# Horus AIS Site

Site vitrine statique pour Horus AIS.

## Structure

- `index.html` — page d'accueil (hero avec animation)
- `liens.html` — page de contact rapide
- `contact.html` — informations de contact
- `prestations.html` — prestations et tarifs
- `mentions-legales.html` — mentions légales
- `assets/` — images (logos, fonds, etc.)

## Déploiement

Site statique, prêt pour Cloudflare Pages ou tout hébergeur statique.

Pour prévisualiser en local : ouvrir `index.html` dans un navigateur, ou lancer un serveur simple :

```bash
python -m http.server 8000
```

Puis aller sur http://localhost:8000
